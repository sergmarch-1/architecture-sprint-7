Требования к безопасности

I. Защита данных и трафика

1. Все передаваемые данные должны быть зашифрованы (TLS 1.2/1.3);
2. Внешняя платформа не должна хранить чувствительные данные пользователей без согласия;
3. Настройка Rate Limiting для API Gateway.

II. Аудит и контроль доступа

1. Вся аутентификация и авторизация должны логироваться в централизованной системе мониторинга;
2. Настройка RBAC-политики в API Gateway;
3. Необходимы механизмы отзыва токенов и блокировки учетных записей в случае компрометации;
4. Регулярный аудит и тестирование на уязвимости.

III. Протоколы аутентификации и авторизации

1. OAuth 2.0 - для авторизации собственников (JWT-токены с минимальными привилегиями, Refresh-токены с ограниченным сроком действия);
2. Mutual TLS (mTLS) + API Keys - для взаимодействия между системами PropDevelopment и Умным Домом;
3. Webhooks - для получения уведомлений о событиях распознования номера \ лица.
